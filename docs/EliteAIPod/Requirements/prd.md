## User Stories

### US-001 — Guest Account Registration

**As a** potential guest
**I want** to create an account using my email address
**So that** I can book stays, manage my trips, and communicate with hosts.

- **Epic:** User Authentication & Profile Management
- **Priority:** critical
- **Story Points:** 3

**Acceptance Criteria:**
- Given I am on the registration page, When I enter my name, email, and a valid password, Then my account is created and I am logged in.
- Given I try to register with an email that already exists, When I submit the form, Then I see an error message indicating the email is already in use.

### US-002 — Host Account Registration

**As a** property owner
**I want** to create a host account
**So that** I can list my properties and start earning rental income.

- **Epic:** User Authentication & Profile Management
- **Priority:** critical
- **Story Points:** 3

**Acceptance Criteria:**
- Given I am on the registration page, When I select the 'Host' account type and complete the sign-up form, Then my host account is created.
- Given my account is created, When I log in, Then I am directed to a host dashboard to begin creating a listing.

### US-003 — User Login

**As a** registered user
**I want** to log in to my account with my email and password
**So that** I can access my personalized dashboard and information.

- **Epic:** User Authentication & Profile Management
- **Priority:** critical
- **Story Points:** 2
- **Depends on:** US-001
