## User Flows

### Load Message Timeline _(happy path)_
1. **GuestbookHome**: User navigates to the application root → React app mounts, sets loading=true, and calls GET /api/v1/messages _(Loading spinner is displayed during the fetch)_2. **GuestbookHome**: API returns 200 OK with message array → loading=false, messages are rendered in MessageTimeline _(Rendered in reverse chronological order)_
**Error scenarios:**
- API returns 500 error: Timeline displays 'Could not load messages.'
- API returns empty array: Timeline displays 'No messages have been posted yet.'

### Submit New Message _(happy path)_
1. **GuestbookHome**: User types in Name and Message fields → Post button becomes enabled once both fields have non-empty text _(Local component state updates on change)_2. **GuestbookHome**: User clicks Post button → isSubmitting=true, Post button disables, POST /api/v1/messages is called _(Form fields remain populated during submission)_3. **GuestbookHome**: API returns 201 Created with new message object → New message is prepended to timeline, fields are cleared, isSubmitting=false _(Optimistic UI update without full page refresh)_
**Error scenarios:**
- API returns 400 or 500: Form displays user-friendly error message, isSubmitting=false, Post button re-enables, fields retain user input.
