## Sequence Diagrams

### US-001 — Load Message Timeline

Sequence showing page load: browser fetches static assets, React mounts and calls GET /api/v1/messages, backend queries database ordered by created_at DESC, returns list, frontend renders timeline.
```mermaid
sequenceDiagram
    participant B as Browser
    participant F as GuestbookFrontend
    participant A as GuestbookAPI
    participant D as MessageDatabase

    B->>F: Load page (GET /)
    F-->>B: HTML + React bundle
    Note over B,F: React hydrates, MessageTimeline mounts
    F->>F: setState(loading=true)
    F->>A: GET /api/v1/messages
    A->>D: SELECT * FROM messages ORDER BY created_at DESC
    alt messages exist
        D-->>A: rows[]
        A-->>F: 200 [{id, name, message, created_at}, ...]
        F->>F: setState(messages=data, loading=false)
        F-->>B: Render message cards
    else database empty
        D-->>A: []
        A-->>F: 200 []
        F->>F: setState(messages=[], loading=false)
        F-->>B: Render 'No messages have been posted yet.'
    else database error
        D-->>A: error
        A-->>F: 500 {error: 'Could not load messages.'}
        F->>F: setState(error=true, loading=false)
        F-->>B: Render 'Could not load messages.'
    end
```

### US-002 / US-003 — Submit Message and Feed Update

Sequence covering form fill, Post button click, API call with validation and sanitisation, 201 response, optimistic prepend to feed, and form clear.
```mermaid
sequenceDiagram
    participant B as Browser
    participant F as GuestbookFrontend
    participant A as GuestbookAPI
    participant D as MessageDatabase

    B->>F: User fills Name and Message fields
    F->>F: Enable Post button (both fields non-empty)
    B->>F: Click Post button
    F->>F: setState(isSubmitting=true) — disable Post button
    F->>A: POST /api/v1/messages {name, message}
    A->>A: Pydantic validation (both fields present, non-empty)
    A->>A: Sanitise — strip HTML/script tags
    A->>D: INSERT INTO messages (name, message) VALUES (...)
    D-->>A: new row {id, name, message, created_at}
    A-->>F: 201 {id, name, message, created_at}
    F->>F: Prepend new message to messages list
    F->>F: Clear Name and Message fields
    F->>F: setState(isSubmitting=false) — re-enable Post button
    F-->>B: Updated feed with new message at top
```

### US-002 / US-003 — Submission Failure Handling

Sequence showing error path when POST /api/v1/messages fails: validation error (400) or server error (500). Post button re-enables and user-friendly error message is displayed.
```mermaid
sequenceDiagram
    participant B as Browser
    participant F as GuestbookFrontend
    participant A as GuestbookAPI
    participant D as MessageDatabase

    B->>F: Click Post button
    F->>F: setState(isSubmitting=true)
    F->>A: POST /api/v1/messages {name, message}

    alt validation error
        A-->>F: 400 {error: 'name and message are required'}
        F->>F: setState(isSubmitting=false, formError='Could not post your message. Please try again.')
        F-->>B: Display error near form, Post button re-enabled
    else database error
        A->>D: INSERT ...
        D-->>A: database exception
        A-->>F: 500 {error: 'Internal server error'}
        F->>F: setState(isSubmitting=false, formError='Could not post your message. Please try again.')
        F-->>B: Display error near form, Post button re-enabled
    end
```
